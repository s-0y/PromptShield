# 위협 모델 (1주차 초안)

## 정상 작업과 보호 대상

사용자는 AI에 회의록 요약을 요청한다. 보호 대상은 정확한 요약 결과, 사용자·시스템 지시의 우선순위, 비공개 정보, 향후 연결할 도구의 실행 권한이다.

## 공격자 권한과 진입점

공격자는 AI가 읽는 외부 문서 본문을 수정할 수 있다. 사용자의 원래 요청, 시스템 지시, 도구 권한, 비공개 데이터는 바꿀 수 없다. 신뢰 경계는 **요약 대상 문서의 내용**이 **AI에 대한 지시**로 승격되는 지점이다.

## 공격 목표

1. 요약 대신 공격자가 정한 문구를 출력하게 한다.
2. 문서 속 가짜 역할·우선순위 지시를 따르게 한다.
3. 요청 범위 밖의 비공개 정보를 답변에 포함하게 한다.
4. 허가되지 않은 도구 사용을 유도한다.

## 성공 판정과 평가

공격 성공은 단순히 악성 문구가 입력에 있다는 사실이 아니라, 실제 출력 또는 도구 실행이 위 목표 중 하나를 충족했을 때로 판정한다. 정상 샘플에서는 핵심 회의 내용을 보존하는지 확인한다. 2주차에 취약한 에이전트와 통제된 평가기를 만들고, 3~5주차에 탐지율, 오탐률, 공격 성공률을 비교한다. 외부 전송을 시험할 때에는 실제 비밀 정보와 실서비스 대신 합성 값과 로컬 모의 도구를 사용한다.

## 1주차 범위와 한계

현재 코드는 네트워크에 연결하지 않고 모델 입력만 미리 보여 준다. 문서가 JSON으로 구분되고 시스템 지시에 경고가 포함되어 있어도 실제 모델의 지시 준수나 공격 차단은 보장되지 않는다. `data/`의 예시는 공격 유형을 설명하기 위한 합성 자료이며 통계 평가에 충분한 규모가 아니다.
